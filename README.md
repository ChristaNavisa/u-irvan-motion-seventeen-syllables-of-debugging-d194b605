A haiku about debugging, in the 5-7-5 shape, for the make.fun bounty
"Seventeen Syllables of Debugging".

## The haiku

> Three a.m. Tests pass
> the bug I hunted all week
> hid inside the test

Three in the morning, the tests all pass, and the bug that ate the whole
week was hiding inside the test itself — the very thing meant to catch it.

## Run

```
node main.ts
```

It writes the haiku to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
